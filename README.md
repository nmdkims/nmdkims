## 🏆 Key Projects & Achievements

- 🚀 **Hamaroom** ([hamaroom.com](https://hamaroom.com))  
  An AI-powered service that takes the administrative load off teachers. I own the backend architecture and the LLM integration behind a system that serves thousands of teachers.

- 🏫 **Hama O** *(new)*  
  A next-generation LMS. I am designing and building its Django-based backend architecture.

- 🎓 **TeacherLine** ([teacherline.net](https://teacherline.net))  
  A recruitment platform built exclusively for educators. I designed and implemented the RESTful APIs for authentication, applicant management, and application workflows, along with a database schema built to scale.

- 🧠 **Linkerverse** — **CES Innovation Award**  
  A health analysis service that works from nail images, recognized with a **CES Innovation Award**. My work covered:

  - AI model research and development
  - The image analysis pipeline, from preprocessing to inference
  - Deep learning models for health-related image classification and segmentation
  - Deployment and optimization of those models in production
